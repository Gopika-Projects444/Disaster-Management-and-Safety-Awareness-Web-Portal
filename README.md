# Disaster-Management-and-Safety-Awareness-Web-Portal
A responsive web portal developed using HTML, CSS, and Bootstrap to provide disaster awareness and safety information. Users can select disasters such as floods, tsunamis, earthquakes, cyclones, landslides, and wildfires to view specific Do’s, Don’ts, safety guidelines, and emergency information.
📌 Project Overview

The Disaster Management and Safety Awareness Web Portal is a responsive web-based application designed to provide users with essential safety information during natural disasters.

The dashboard displays different disaster categories as cards. Each disaster has an individual webpage containing its overview, safety precautions, Do's, Don'ts, guidelines, and emergency information.

🎯 Objectives
Create awareness about natural disasters.
Provide easy-to-understand safety information.
Help users understand what to do before, during, and after disasters.
Provide disaster-specific Do's and Don'ts.
Provide quick access to emergency contact information.
Create a simple and responsive user interface.
